# Grade Calculator

A simple web-based grade calculator that helps students calculate their average score and letter grade across multiple subjects.

##  Features

- Calculate averages from 5 core subjects (Math, English, Physics, Chemistry, Biology)
- Ensures scores are between 0-100
- Automatic conversion to letter grades (A+, B, C, D, F)
- Visual indication of pass (75%+) or fail status
- Clean, modern interface with smooth animations
- Instant calculation upon submission

## How to Use

1. Open the this link: [Here](https://marvelttihu.github.io/grade-calculator/)
2. Input your scores for each subject (0-100 range)
3. Click the "Calculate" button
4. See your average, letter grade, and pass/fail status

### Grading System

| Average Score | Letter Grade |
|---------------|--------------|
| 90-100        | A+          |
| 80-89         | B           |
| 70-79         | C           |
| 60-69         | D           |
| 0-59          | F           |

**Pass Threshold**: 75% or higher
